# Beauty Plus Salon, maquette SEO de /hair/shampoos

Maquette datashake de la page catégorie https://www.beautyplussalon.com/hair/shampoos, retravaillée pour le SEO. Formulaires et panier désactivés, page en noindex.

Modifications par rapport à la page live :
- Title et H1 retravaillés
- Intro courte et visible (3 lignes) à la place du texte de 860 mots caché sous un « show more »
- Bloc de maillage vers les 12 principales marques de shampoing
- Noms de produits sortis des H2 (32 H2 sur la page live)
- Contenu SEO en bas de page optimisé dans Corpus (score 84, mot-clé « salon shampoo »), début visible et suite sous « Show more », résumé, tableau par besoin, 7 liens internes, FAQ avec balisage FAQPage
- Filtres sticky en desktop

Le bouton « SEO mockup: show changes » en bas à gauche affiche les annotations.

Les images produits sont servies depuis archive.org.

Pour reconstruire `index.html`, modifier `src/top.html`, `src/bottom.html` ou `src/seo.css`, puis lancer `src/build.py` avec le HTML et le CSS d'origine de la page (non versionnés ici).
